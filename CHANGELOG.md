# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-10-10

- Add distinct first-progress, idle-activity, and total deadlines for async iterables.
- Add progress, heartbeat, and ignored-item classification without filtering values.
- Add caller-owned `AbortSignal` support and best-effort iterator cleanup.
- Ship ESM, CommonJS, and TypeScript declarations with zero runtime dependencies.
